# 个人网站工程质量基线

## 范围

在不重构整个遗留仓库的前提下，为当前首页、项目、文章、案例与 Netlify 发布路径建立最小可执行质量基线。

## 小型故事卡

### Q1 可重复的本地门禁

验收：新环境执行 `npm ci && npm run verify`，格式、lint、关键类型、业务契约、静态构建和浏览器测试全部自动执行，任一失败返回非零退出码。

### Q2 内容数据契约

验收：重复项目 ID、无效 Web2 / Web3 排序、断裂的案例引用、错误文章系列顺序或缺失本地图片都会让测试失败。

### Q3 Token 证据图关键交互

验收：桌面和移动端均验证打开、居中、键盘焦点、关闭恢复与减少动态效果偏好。

### Q4 可审查的生产发布

验收：Netlify 构建配置进入仓库；线上构建元数据与合并 SHA 一致后，生产冒烟才通过。

### Q5 合并保护

验收：`main` 必须通过 Pull Request 和 `quality` 状态检查；遗留 GitHub Pages 被关闭。
