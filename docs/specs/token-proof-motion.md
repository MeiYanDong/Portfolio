# Token 证据图动效规格

## 用户故事

作为首次访问网站的观众，我可以从首页的 Token 使用指标打开真实数据截图，在不离开当前页面的情况下查看证据，并通过键盘或鼠标安全关闭。

## 验收标准

1. 点击缩略图后，图片从实际缩略图位置放大到视口中央，使用已选定的 03「3D 翻转」路径。
2. 打开后页面滚动锁定，焦点进入关闭按钮；`Tab` 不得逃出模态框。
3. `Escape`、关闭按钮和遮罩空白区域都可以关闭预览。
4. 关闭后图片返回原位置，焦点回到触发按钮，页面滚动恢复。
5. `prefers-reduced-motion: reduce` 下不执行 3D 翻转，使用 160ms 淡入淡出。
6. 桌面和移动端的放大图均在视口中央且不超出安全边距。

## 设计与实现边界

- 首页与 Lab 共用 `lib/tokenImageMotion.js`，Lab 不维护第二份算法。
- 原始证据图片仍是历史截图，图内 306 亿与首页当前 40B+ 分开表述。
- 本功能不引入图库、轮播、手势缩放或图片编辑。

## 自动验证

`tests/e2e/content-navigation.spec.js` 验证放大尺寸、居中、滚动锁定、焦点约束、关闭后焦点恢复，以及减少动态效果偏好。
